# T-105. Редактор координат маршрута

- **Этап:** M1
- **Модули:** `tools/route-editor/`
- **Зависит от:** ничего (формат `route.json` из data.md)
- **Размер:** S
- **Прочитать:** [data.md](../architecture/data.md#routeroutejson), [map.md](../architecture/map.md)

## Зачем

На финальной карте горы и реки лягут не точно там, где на схеме. Владельцу нужно за вечер переставить 51 веху и промежуточные точки по готовой картинке, не правя JSON руками.

## Что сделать

Одна HTML-страница `tools/route-editor/index.html` (можно с соседним `editor.js` и `editor.css`), без сборки, без внешних CDN, работает офлайн в Chrome при открытии файла с диска.

1. Загрузить картинку карты (выбор файла, любой PNG/JPG/WebP, в том числе 6144×6144).
2. Загрузить `route.json` (выбор файла).
3. Показать карту с зумом колесом и прокруткой перетаскиванием.
4. Нарисовать линию маршрута по `point` и `via`, большие вехи кружками с номером, малые точками, промежуточные точки маленькими квадратами.
5. Перетаскивание любой точки мышью.
6. Добавить промежуточную точку: двойной клик по линии между вехами. Удалить: клик с зажатым Alt (или кнопка в панели).
7. Боковая панель: список вех (номер, id, км, координаты), клик по строке центрирует карту на вехе, подсветка вех, у которых разрыв до предыдущей больше 100 км.
8. Экспорт: скачать `route.json`. Меняются только `point` и `via`, остальные поля и порядок ключей сохраняются, координаты округляются до 4 знаков, отступ 2 пробела.
9. Отмена последнего действия (Ctrl+Z, хотя бы 20 шагов).
10. Короткая инструкция в `tools/route-editor/README.md`.

## Чего не делать

- Не редактировать км, id, типы вех: это правится в JSON руками.
- Не тащить фреймворки и npm.

## Критерии приёмки

- Загрузить `image-prompts/map/layout-reference-clean.png` и текущий `route.json` (если T-103 ещё не смёржен, тестовый JSON из 5 вех в `tools/route-editor/sample-route.json`), сдвинуть одну веху, экспортировать: `diff` показывает изменение только у этой вехи.
- Карта 6144×6144 листается без заметных тормозов в Chrome на ноутбуке.

## Тесты

Автотестов нет. В PR скриншот редактора и `diff` из критерия выше.

## Ручная проверка

Владелец открывает `index.html` локально, грузит схему и маршрут, переставляет пару точек, экспортирует.
