# T-403. Карточка вехи и журнал

- **Этап:** M4
- **Модули:** `:feature:journal`
- **Зависит от:** T-003, T-102, T-103
- **Размер:** M
- **Прочитать:** [prd.md](../product/prd.md) US-6, US-7, [game-rules.md](../product/game-rules.md) раздел 6, [content-pack.md](../architecture/content-pack.md), файл любой вехи в `image-prompts/locations/` (раздел про кроп 1:1)

## Зачем

Карточка вехи это награда за прогулку: картинка и кусочек истории. Журнал даёт ощущение пройденного пути. Без них приложение просто счётчик.

## Что сделать

### Карточка: `WaypointRoute(id, fromQueue)`

| Состояние вехи | Что показываем |
|---|---|
| Пройдена, большая | `Illustration` 3:2 во всю ширину; «Веха 7 из 23»; `title`; `place`; «По книге: {season}»; `story`; разделитель; «Пройдено 12 марта 2027 · 737 км от старта» |
| Пройдена, малая | без картинки, небольшой орнамент из дизайн-системы или ничего; `title`; `story`; дата прохождения |
| Не пройдена (следующая или впереди) | `Illustration` с `assetPath = null` (запасной пергамент с номером); `title`; «Через 390 км»; истории, сезона и картинки нет |

- Внизу пройденной карточки: «Дальше: Карадрас, через 390 км» (для последней вехи не показывать).
- `fromQueue = true`: кнопка «Дальше» ведёт на следующую непросмотренную большую веху (по км), если её нет, закрывает карточку. При открытии карточка помечается просмотренной (`markSeen`).
- `fromQueue = false`: обычная стрелка «Назад».
- Километры в реальных км (с учётом `routeScale`), даты по локали.

### Журнал: `JournalRoute`

- Заголовок: «Пройдено 7 из 23 больших вех · 812 км».
- Список всех вех по порядку:
  - пройденная большая: миниатюра 1:1 (центральный кроп иллюстрации или запасной пергамент), номер, `title`, дата;
  - пройденная малая: компактная строка с точкой, `title`, дата;
  - следующая: выделенная `LwCard`, `title`, «через N км»;
  - впереди: приглушённый `title` и расстояние от старта.
- При открытии прокрутка к следующей вехе.
- Тап по любой строке открывает карточку с `fromQueue = false`.

### Общее

- `WaypointViewModel` и `JournalViewModel` на `ObserveProgress` и `ContentRepository`.
- Иллюстрации только через `Illustration` из дизайн-системы. Фича не проверяет наличие файлов.

## Чего не делать

- Не показывать историю и картинку будущих вех.
- Не держать список вех в фиче: только из `Route`.

## Критерии приёмки

- Три состояния карточки достижимы и покрыты тестами.
- Цепочка «Дальше» из трёх непросмотренных больших вех проходит их по порядку и помечает просмотренными все три.
- Журнал на старте, в середине пути и после финиша выглядит правильно.
- Отсутствие картинки не ломает ни карточку, ни журнал.

## Тесты

- `WaypointViewModelTest`: состояния, очередь «Дальше», `markSeen`, реальные км при `routeScale = 0.5`.
- `JournalViewModelTest`: группировка, прокрутка к следующей, заголовок.
- Roborazzi: карточка большой пройденной с картинкой и без, малой, будущей; журнал в начале, в середине, в конце; ru и en; карточка с `fontScale = 1.5`.

## Ручная проверка

1. Положить в `assets/illustrations/waypoints/` любую картинку 1800×1200 с именем `01-bag-end.webp`: карточка Бэг-Энда показывает её, в журнале центральный кроп.
2. Открыть журнал, тапнуть пройденную и будущую вехи: карточки в двух разных состояниях.
3. После T-402 (там появится отладочное меню и очередь карточек): дойти до вехи через «+10 км», карточка открывается из очереди, «Дальше» закрывает её.
