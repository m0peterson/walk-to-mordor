# T-103. Контент: маршрут, тексты, загрузка

- **Этап:** M1
- **Модули:** `:content`, `:core:data`
- **Зависит от:** T-101
- **Размер:** L
- **Прочитать:** [content-pack.md](../architecture/content-pack.md) (особенно «Правила текстов»), [data.md](../architecture/data.md#контент), [game-rules.md](../product/game-rules.md) раздел 1, [image-prompts/map/world-map.md](../../image-prompts/map/world-map.md) (таблица координат), [layout-reference-annotated.png](../../image-prompts/map/layout-reference-annotated.png), файлы `image-prompts/locations/*.md`

## Зачем

Маршрут и тексты это и есть содержание игры. Задача делает рабочую черновую версию, которую владелец потом вычитает и уточнит, и загрузчик с проверками, чтобы ошибки в данных ловились тестами.

## Что сделать

1. **`content/src/main/assets/route/route.json`** по формату из data.md:
   - 51 веха из черновой таблицы game-rules.md, с теми же `id`, типами и км;
   - `point` больших вех: из таблицы «Вехи на схеме» в `world-map.md` (проценты → доли, 3 знака);
   - `point` малых вех: на линии маршрута между соседними большими, по красному пунктиру на `layout-reference-annotated.png`, примерно пропорционально км;
   - `via`: 0-4 промежуточные точки там, где пунктир на схеме заметно изгибается (Ривенделл → Карадрас уходит на юго-запад и обратно, Андуин, обход Эмин Муил, путь вдоль Эфел Дуата). Точность не важна: финальные точки владелец снимет редактором T-105;
   - `illustration` у больших вех: `illustrations/waypoints/NN-<id>.webp`, где `NN-<id>` совпадает с именем файла промпта в `image-prompts/locations/`.
2. **`content/src/main/assets/texts/ru.json` и `en.json`** по формату из data.md:
   - `appTitle`, `routeTitle`, `disclaimer` («Неофициальное фанатское приложение. Не связано с правообладателями произведений Дж. Р. Р. Толкина и фильмов по ним.» и английский аналог), `canonPaceLabel`;
   - все шесть ключей `screens` (по смыслу картинок в `image-prompts/screens/`: начало пути, выбор срока, «каждый твой шаг это шаг по карте», победа, победа с продлением, срок вышел с надеждой);
   - для каждой из 51 вехи `title`; у больших `place`, `season` (из промптов), `story`; у малых `story` 1-2 предложения;
   - строго по правилам текстов из content-pack.md: своими словами, без цитат, по книге, без спойлеров вперёд, лимиты длины.
3. **`ContentPaths`** в `:content`: константы путей к позам, экранным картинкам, маркерам, `map/meta.json`, `route/route.json`, `texts/`.
4. **`AssetContentRepository`** в `:core:data` (реализует `ContentRepository`):
   - DTO на kotlinx.serialization → доменные модели. `legs[i]` = `[point вехи i] + via вехи i+1 + [point вехи i+1]`;
   - `mapAspect` из `map/meta.json`; если файла нет, 1.0 и предупреждение в лог;
   - проверка `RouteValidator` плюс правило 7 (тексты для всех вех на всех языках). В debug при ошибках падает с понятным сообщением, в release логирует и работает с тем, что есть;
   - `texts(locale)`: язык из локали, запасной английский; кэш в памяти;
   - Hilt-модуль `ContentModule` в `:core:data`.

## Контракты

- Отдаёт `ContentRepository` и реальные данные маршрута.
- Формат JSON из data.md. Нужно поле, которого там нет: добавь в data.md в этом PR.

## Чего не делать

- Не класть картинки. Только JSON и пути.
- Не создавать `content/LICENSE` (решение владельца D-4).
- Не дублировать названия вех в `strings.xml`.

## Критерии приёмки

- Реальный `route.json` проходит `RouteValidator` без единой ошибки.
- Для каждой из 51 вехи есть `title` на двух языках, для каждой большой `story` на двух языках.
- Для каждой большой вехи существует файл `image-prompts/locations/NN-<id>.md` с тем же номером и id.
- Максимальный разрыв между вехами не больше 100 км.
- Ни одной цитаты: в PR агент перечисляет, как проверял (например, тексты написаны с нуля, без копирования, и сверены с правилами).
- `texts` для немецкой локали отдаёт английский.

## Тесты

- `RealRouteContentTest` (JVM, читает файлы из `content/src/main/assets` по относительному пути): парсинг, валидация, полнота текстов, совпадение с файлами промптов, лимиты длины `story`.
- `AssetContentRepositoryTest` (Robolectric): загрузка из assets, отсутствующий `meta.json`, откат локали, кэш.

## Ручная проверка

Владелец (задача A-5) читает `texts/ru.json` целиком и правит тон и факты отдельным коммитом.
