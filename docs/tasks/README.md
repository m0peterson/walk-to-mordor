# Задачи для агентов

Каждый файл здесь: самодостаточное ТЗ на один PR. Порядок и зависимости в [roadmap.md](../roadmap.md), общие правила в [AGENTS.md](../../AGENTS.md).

## Как запускать

1. Убедиться, что все задачи из «Зависит от» смёржены в `main`.
2. Завести issue по шаблону «Задача для агента» со ссылкой на файл задачи (или просто дать агенту путь к файлу).
3. Агенту: «Выполни задачу `docs/tasks/T-XXX-....md` по правилам из AGENTS.md».
4. Агент делает ветку `task/T-XXX-...`, код, тесты, PR.
5. CI зелёный → владелец читает PR, проходит «Ручную проверку», мёржит (squash).
6. Если в PR есть «Решения по ходу» или «Замечено по пути», владелец решает, нужна ли новая задача или правка документов.

Агенты не меняют файлы задач и роадмап. Если ТЗ устарело, это правит владелец отдельным коммитом.

## Шаблон задачи

```markdown
# T-XXX. Название

- **Этап:** M?
- **Модули:** где пишется код
- **Зависит от:** задачи, которые должны быть смёржены
- **Размер:** S / M / L
- **Прочитать:** документы, без которых задачу не сделать

## Зачем
Одним абзацем: какую проблему пользователя или проекта решает.

## Что сделать
Нумерованный список. Конкретные классы, файлы, поведение.

## Контракты
Что задача отдаёт другим задачам и что берёт у них.

## Чего не делать
Явные границы, чтобы не залезть в соседнюю задачу.

## Критерии приёмки
Проверяемые утверждения. Каждое можно подтвердить тестом, скриншотом или командой.

## Тесты
Какие тесты обязательны.

## Ручная проверка
Шаги для владельца на телефоне, если без телефона не проверить.
```
