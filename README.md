# Walk to Mordor

Android-шагомер: реальные шаги двигают двух хоббитов по карте Средиземья от Шира до Роковой горы. Пользователь выбирает срок, приложение показывает, идёт ли он в графике и сколько нужно пройти сегодня. Офлайн, без аккаунта, без доступа в интернет.

Статус: спроектировано, код ещё не начат.

## Как идёт работа

1. Владелец берёт следующую задачу из [роадмапа](docs/roadmap.md), у которой смёржены зависимости.
2. Агент получает путь к файлу задачи и выполняет её по [AGENTS.md](AGENTS.md): ветка, код, тесты, PR.
3. CI проверяет сборку, стиль, тесты, скриншоты и отсутствие доступа в интернет.
4. Владелец ревьюит, проходит «Ручную проверку» из задачи, мёржит.

Параллельно владелец генерирует картинки по промптам. Код работает на заглушках, пока картинок нет.
